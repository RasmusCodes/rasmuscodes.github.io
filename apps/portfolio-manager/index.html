Research signals

Each research system hands over the same record: instrument, score, confidence, horizon, provenance, model version and track record. Built-in signals are computed from public data, with track records measured month by month on information available at the time. Illustrative rows show the other research families and are off by default.

Combination

Expected excess return = equilibrium return + IC × volatility × combined z-score (Grinold). Bayesian model averaging and the ridge ensemble need the full signal history and run in the Python engine; their results are in Study results.

Estimation error lab

Treat the current inputs as the truth, simulate return histories of the chosen length from them, re-estimate, re-optimize, and score each portfolio with the TRUE inputs. The gap between promised and delivered Sharpe ratios is what estimation error costs.

Walk-forward backtest

At each rebalance the method sees only the trailing window, trades at month end paying costs on the weight traded, then earns the next month's returns. Constraints come from the Construct tab.
